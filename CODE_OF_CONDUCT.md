# Code of Conduct

To ensure our project remains a constructive and efficient environment, we expect all participants to adhere to the following standards:

## Expectations

* **Responsiveness:** If you open an issue, you are expected to monitor it and respond to requests for clarification or logs within 48 hours. If we do not hear from you, the ticket will be closed.

* **Stay On-Topic:** Please do not hijack existing tickets to discuss unrelated problems. Open a new issue if your issue is not exactly the same as the one currently being discussed.

* **Respectful Communication:** Treat all contributors with kindness. Aggressive or malicious reporting will not be tolerated.

* **Quality Over Quantity:** Please search existing issues before opening a new one. Duplicate or incomplete bug reports waste maintainer time.

* **Constructive Feedback:** When providing feedback, focus on the technical aspects of the issue rather than personal critiques. We value contributions that help move the project forward effectively.

* **Accountability:** By opening an issue, you accept responsibility for maintaining the dialogue required to resolve it. If you are unable to participate for an extended period, please inform the maintainers.

## Consequences

We prioritize the health of our community. Failure to follow these guidelines may result in:

1. Being asked to revise your issue or conduct.

2. Having your issue closed without resolution.

3. Being blocked from the repository if behavior is found to be malicious, persistently disruptive, or if the 48-hour response policy is repeatedly ignored.

*By participating in this repository, you agree to uphold these standards.*
