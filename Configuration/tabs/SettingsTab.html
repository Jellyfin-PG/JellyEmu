IGDB Metadata (via Twitch)

Used for game descriptions, release dates, and cover art. Register your app at dev.twitch.tv/console/apps and set the OAuth redirect to http://localhost.

RAWG Metadata

Used as a fallback provider for game metadata and screenshots. Get your free API key at rawg.io/apidocs.

SteamGridDB Images

Used for high-quality game grids, heroes, and logos. Get your API key at steamgriddb.com/profile/api.

TheGamesDB Metadata & Images

Community-driven open database for retro game metadata, front/back box art, fanart, and logos. Get your free API key at thegamesdb.net/user/api.

Romm Integration Disabled by default

Connects to your self-hosted Romm instance for metadata, cover art, save-state cloud sync, playtime reporting, collection sync, and screenshot push. Requires Romm v3.4 or later.

Enable Romm integration Enables metadata, cover art, save sync, playtime reporting, collection sync and screenshot push.

Credentials are sent as HTTP Basic Auth on every request to your Romm instance. A secure HTTPS connection is strongly recommended.

Romm Features (requires Romm enabled above)

Save-state sync Pull save from Romm on launch if it's newer; push to Romm after each save.
Playtime reporting Send session playtime to Romm when a game session ends.
Collection sync Import Romm collections as Jellyfin collections.
Screenshot push Send in-game screenshots to Romm when you take one.

Netplay

Provide your netplay server address to enable multiplayer via EmulatorJS. Leave blank to disable netplay. Requires a running EmulatorJS netplay server.

Vantage

Displays an "Open in Vantage" button on game pages and menus to launch games in Vantage.

Vantage Toggles whether the "Open in Vantage" button is displayed.

Frontend Injection Method

Choose the mechanism used to modify jellyfin frontend. Off will use File Transformation plugin, On will use Loom plugin if installed, Loom is the optimized way to modify frontend ui.

Use Loom Injector (Memory-based middleware) When active and the Loom plugin is installed, UI injection is managed dynamically by Loom.

EmulatorJS Distribution Channel

Select the EmulatorJS release channel. Stable is recommended for most platforms. Nightly is required for experimental cores such as Nintendo 3DS (Azahar).

ROM Download Location

Select a Jellyfin library folder where downloaded ROMs will be stored.

Marketplace Feed URL

Provide a URL pointing to a Scraper JSON file containing metadata sources.

System BIOS Folder
