Romm Integration

Requires Romm v3.4+

Connects to your self-hosted Romm instance for metadata, cover art, save-state cloud sync, playtime reporting, collection sync, and screenshot push.

Enable Romm integration Enables metadata, cover art, save sync, playtime reporting, collection sync and screenshot push.

Credentials are sent as HTTP Basic Auth on requests to your Romm instance. A secure HTTPS connection is strongly recommended.

Romm Sync Features

Save-state sync Pull save from Romm on launch if it's newer; push to Romm after each save.
Playtime reporting Send session playtime to Romm when a game session ends.
Collection sync Import Romm collections as Jellyfin collections.
Screenshot push Send in-game screenshots to Romm when you take one.

Vantage Launcher

Displays an "Open in Vantage" button on game detail pages to launch local games in the Vantage desktop client.

Vantage Launch Button Toggles whether the "Open in Vantage" button is displayed on game cards and details.
