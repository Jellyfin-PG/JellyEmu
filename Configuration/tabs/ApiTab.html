RetroArch Integration

Endpoints exposed for RetroArch system streaming and playlist auto-generation.

GET /jellyemu/retroarch/playlist

Downloads JellyEmu.lpl, the full library playlist. Copy it to your RetroArch playlists/ folder to stream ROMs directly over HTTP.

GET /jellyemu/retroarch/playlist/{system}

Downloads a per-system playlist JellyEmu-{system}.lpl. Replace {system} with a platform tag like NES or SNES.

GET /jellyemu/retroarch/launch/{itemId}

Deep-link launch handler. Opening this endpoint on a system with RetroArch installed initiates the game directly.

GET /jellyemu/retroarch/info

Returns a JSON summary of all detected systems, total game counts, and playlist configuration details.

Core File Delivery

Endpoints managing direct game ROM delivery and packaging.

GET /jellyemu/rom/{itemId}

Streams the raw game ROM binary file. Used for RetroArch playback and download routing.

GET /jellyemu/rom/download-zip/{itemId}

Builds and streams a ZIP file packaging all multi-part installer files (designed for Windows/GOG installer packages).

Saves & Preferences

Endpoints managing cloud saves, SRAM, state states, and settings.

GET /jellyemu/saves/{itemId}/slots

Retrieves a list of saved state slots, modified dates, and active emulator details for the given game.

GET POST /jellyemu/saves/{itemId}/slots/{slot}

Downloads (GET) or uploads (POST) the save state file for the specified slot. Slot 100 corresponds to auto-saves, and slot 99 corresponds to disc-swapping saves.

GET POST /jellyemu/saves/{itemId}/prefs

Downloads (GET) or uploads (POST) EmulatorJS controller mapping and preferences JSON.
