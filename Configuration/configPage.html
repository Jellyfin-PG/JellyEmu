Console Distribution

IGDB Metadata (via Twitch)

Used for game descriptions, release dates, and cover art. Register your app at dev.twitch.tv/console/apps and set the OAuth redirect to http://localhost.

RAWG Metadata

Used as a fallback provider for game metadata and screenshots. Get your free API key at rawg.io/apidocs.

SteamGridDB Images

Used for high-quality game grids, heroes, and logos. Get your API key at steamgriddb.com/profile/api.

Romm Integration Disabled by default

Connects to your self-hosted Romm instance for metadata, cover art, save-state cloud sync, playtime reporting, collection sync, and screenshot push. Requires Romm v3.4 or later.

Enable Romm integration Enables metadata, cover art, save sync, playtime reporting, collection sync and screenshot push.

Credentials are sent as HTTP Basic Auth on every request to your Romm instance. A secure HTTPS connection is strongly recommended.

Romm Features (requires Romm enabled above)

Save-state sync Pull save from Romm on launch if it's newer; push to Romm after each save.
Playtime reporting Send session playtime to Romm when a game session ends.
Collection sync Import Romm collections as Jellyfin collections.
Screenshot push Send in-game screenshots to Romm when you take one.

Netplay

Provide your netplay server address to enable multiplayer via EmulatorJS. Leave blank to disable netplay. Requires a running EmulatorJS netplay server.

RetroArch Integration

Endpoints exposed for RetroArch system streaming and playlist auto-generation.

GET /jellyemu/retroarch/playlist

Downloads JellyEmu.lpl, the full library playlist. Copy it to your RetroArch playlists/ folder to stream ROMs directly over HTTP.

GET /jellyemu/retroarch/playlist/{system}

Downloads a per-system playlist JellyEmu-{system}.lpl. Replace {system} with a platform tag like NES or SNES.

GET /jellyemu/retroarch/launch/{itemId}

Deep-link launch handler. Opening this endpoint on a system with RetroArch installed initiates the game directly.

GET /jellyemu/retroarch/info

Returns a JSON summary of all detected systems, total game counts, and playlist configuration details.

Core File Delivery

Endpoints managing direct game ROM delivery and packaging.

GET /jellyemu/rom/{itemId}

Streams the raw game ROM binary file. Used for RetroArch playback and download routing.

GET /jellyemu/rom/download-zip/{itemId}

Builds and streams a ZIP file packaging all multi-part installer files (designed for Windows/GOG installer packages).

Saves & Preferences

Endpoints managing cloud saves, SRAM, state states, and settings.

GET /jellyemu/saves/{itemId}/slots

Retrieves a list of saved state slots, modified dates, and active emulator details for the given game.

GET POST /jellyemu/saves/{itemId}/slots/{slot}

Downloads (GET) or uploads (POST) the save state file for the specified slot. Slot 100 corresponds to auto-saves, and slot 99 corresponds to disc-swapping saves.

GET POST /jellyemu/saves/{itemId}/prefs

Downloads (GET) or uploads (POST) EmulatorJS controller mapping and preferences JSON.

Thank you for using JellyEmu

JellyEmu is an open-source plugin designed to seamlessly connect your Jellyfin media library to EmulatorJS and RetroArch, enabling in-browser gameplay, cloud save synchronisation, playtime tracking, and self-hosted Romm manager integrations.

Development is community-driven. If you encounter bugs, want to propose features, or want to contribute to the code, please visit our repository on GitHub.
