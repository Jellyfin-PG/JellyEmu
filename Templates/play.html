PlayStation 2 Memory Cards

Play! uses simulated 8MB PlayStation 2 Memory Cards. Game progress is synced automatically to your Jellyfin profile.

DualShock 2 Controller Mapping

USB & Bluetooth gamepads (Xbox, PlayStation, etc.) are automatically mapped with full Dual Analog Stick support.

Keyboard Controls:
  • D-Pad: Arrow Keys
  • Action Buttons: Z (Cross ✕), X (Circle ○), A (Square □), S (Triangle △)
  • Shoulder Buttons: Q / 1 (L1), E / 2 (R1), 3 (L2), 4 / 8 (R2)
  • Thumbstick Clicks: 9 (L3), 0 (R3)
  • Left Analog Stick: T / F / G / H (or W / D)
  • Right Analog Stick: I / J / K / L
  • Select / Start: Right Shift / Enter
